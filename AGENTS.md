# Условия лабораторных работ

- Не менее половины работ выполнять в Anaconda Jupyter Notebook. Остальные можно выполнять в Google Colab. Записывать основную среду каждой работы в README.
- В первой работе продемонстрировать создание и активацию двух окружений, а также проверку и установку пакетов через Navigator и терминал.
- Для каждой работы использовать не менее двух датасетов, сохранять результаты и визуализации. Не повторять датасеты между работами. Реестр использованных наборов данных вести в README.
- Публиковать работы в персональном публичном репозитории GitHub. README описывает структуру проекта. Ноутбуки сохранять вместе с выводом и графиками.
- Для защиты готовить отчёт умеренного объёма по пунктам задания с фактическими результатами.
